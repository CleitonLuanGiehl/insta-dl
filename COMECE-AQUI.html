insta-dl

Baixa o vídeo de um post ou reel do Instagram direto na sua máquina, para você postar no grupo. Não precisa instalar nada.

1 Copiar o link

No Instagram, abra o post e use ··· → Copiar link.

2 Abrir a ferramenta

Nesta mesma pasta, dê duplo clique em:

insta-dl.exe

Abre uma janela com o link que você copiou já preenchido. Clique em Baixar e pronto — o vídeo e a legenda ficam na subpasta videos, com o nome do perfil de origem no arquivo. É só arrastar para o grupo.

Não instala nada na sua máquina. A pasta é autocontida: nada vai para o registro do Windows, nada pede senha de administrador e nada roda sozinho depois. Para desinstalar, apague a pasta.
Esse .exe é confiável? De onde ele veio?

Ele não é um programa empacotado por nós. É o interpretador oficial do Python, do pacote embeddable publicado em python.org, apenas renomeado para insta-dl.exe.

Dá para conferir sozinho: clique com o botão direito no insta-dl.exe → Propriedades → Assinaturas Digitais. Vai aparecer Python Software Foundation, com assinatura válida.

O que a ferramenta faz de fato está nos arquivos de texto da pasta app — pode abrir qualquer um no Bloco de Notas e ler.

Para onde vai o meu link?

Para lugar nenhum além do próprio Instagram. A ferramenta roda na sua máquina e fala direto com o instagram.com, do mesmo jeito que o navegador faz quando você assiste o vídeo. Nenhum site intermediário recebe o link, e nada é enviado para fora.

Para que serve a pasta “sistema”?

É o Python que vem junto, para você não precisar instalar nada. Pode ignorar — mexer ali só quebra a ferramenta. As duas pastas que interessam são videos (o que você baixou) e app (o código).

Não abriu nada quando cliquei

Confira duas coisas:

  • A pasta precisa estar descompactada. Se você abriu o zip e clicou de dentro dele, extraia para uma pasta de verdade primeiro (ex.: C:\insta-dl) e tente de novo.
  • Se apareceu um arquivo erro.log na pasta, mande ele para o Cleiton — é exatamente o que ele precisa para resolver.
E as atualizações?

A própria ferramenta se atualiza: no máximo uma vez por dia ela confere se saiu versão nova, confere a assinatura do pacote e se atualiza sozinha. São poucos kilobytes — o Python que veio junto não é baixado de novo. Você não precisa fazer nada.

Ferramenta interna · qualquer dúvida ou problema, fale com o Cleiton.
